📊 Depreciation Calculator - Excel Project
Overview

This project is an Excel-based Depreciation Calculator that helps users calculate asset depreciation using two widely used accounting methods:
•	Straight-Line Method (SLM)
•	Diminishing Balance Method (DBM)
The workbook automates depreciation calculations, generates year-wise schedules, and provides comparative analysis of both methods for educational and practical accounting purposes.
Project Objective
The primary objectives of this project are:
•	Understand depreciation concepts and accounting terminology.
•	Calculate depreciation using Straight-Line Method.
•	Calculate depreciation using Diminishing Balance Method.
•	Generate year-by-year depreciation schedules.
•	Compare depreciation patterns across different methods.
•	Improve Excel formula and financial modeling skills.

Features
Straight-Line Method
Automatically calculates:
•	Asset Price
•	Annual Depreciation
•	Depreciation Percentage
•	Total Depreciation over Asset Life
•	Depreciated Book Value
•	Balance Verification
